# Review rules

Use AGENTS.md and the mandatory design skill for the implementation baseline. Review actual behavior and material risks, not speculative additions.

## Important

- A regression that loses a local collection, breaks version-2 import, changes card identity or silently removes source cards.
- A new upload of photographs/OCR text, tracking request or cloud collection flow without the requested scope and updated privacy information.
- A secret, token, Apple signing file or personal backup committed or included in downloadable archives.
- Treating a fuzzy OCR match as proof of authenticity, condition, print variant or value.
- Breaking the approved island theme (or reintroducing a dark theme without a decision), brand assets, mobile navigation, keyboard access or contrast for a new component.
- Missing locale keys, translated official card content, broken Unicode matching or conflated interface/card languages.
- Claiming that a repository, workflow, public domain, app build or release is live without evidence.
- Breaking relative links/assets, source-archive inclusion of AGENTS/skill/docs, or the actual checks relevant to a change.

## Minor

- Reimplementing an existing component or adding an unnecessary dependency/framework.
- Documentation or SPEC.md describing old behavior.
- A PR omitting evidence, affected issues or a concise assessment of reversibility and impact.

## Skip

- Preferences that merely reinvent the approved design.
- Requests for unasked abstractions, new storage services or speculative features.
- Repeating checks that already passed without a new reason.
