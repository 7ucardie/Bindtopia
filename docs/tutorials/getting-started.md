# Getting started

Use the portal to find a card, save it and make your first backup.

## 1. Open the catalog

Use the current private preview or serve the source locally as described in the root README. The registered target domain is not evidence that the public site has launched.

## 2. Pick the languages

The globe selector changes interface text. The sidebar's card-language selector changes which catalog and official card names are searched. They are independent. Untranslated interface messages fall back to English.

## 3. Find a card

Search for `Charizard`, `base1-4` or `4/102`. Filter by set if needed. Open a card and compare its artwork, set and collector number. Price links open third-party search results.

## 4. Save it

Select the heart, then open **Saved**. The collection stays in this browser. Clearing site data or switching browsers does not preserve it automatically.

## 5. Try a photo

Open the scanner and choose a clear photograph of one card. Keep both its name and collector number in frame. Correct recognized text if necessary, then inspect the suggested matches. Recognition does not verify authenticity, condition or print variant.

## 6. Back up

Open **Saved → Export saved cards** and store the JSON file somewhere you control. Read [export/import](../how-to/export.md) before clearing the collection or moving devices.
