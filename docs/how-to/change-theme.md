# Change theme

Use the day/night button in the top navigation.

- **Day** selects `poke-island`: the approved sunny brand banner, blue/turquoise accents and warm white surfaces.
- **Night** selects `poke-holo`: Holo Vault, with midnight purple and restrained holographic accents.

The choice stays in the URL, for example `?theme=poke-holo`; there is no persistent theme-tracking identifier. Earlier style-review pages are historical alternatives, not new defaults. Contributors must read the design skill linked by root AGENTS.md before changing either theme.
