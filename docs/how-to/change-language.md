# Change language

Use the globe selector for **interface language**: Dutch, English, German, French, Spanish, Italian, Portuguese or Polish. The browser preference selects a default; unsupported languages fall back to English. A selection is represented in the URL, for example `?ui=fr`.

Choose **card language** in the sidebar separately. Supported catalog choices include English, Japanese, French, German, Italian, Spanish and Portuguese; coverage depends on TCGdex. The scanner chooses its OCR model using the card language. Official card names and descriptions are not rewritten into the interface language.

Legal information is currently available in Dutch and English. The native iPhone development project is not fully localized yet.
