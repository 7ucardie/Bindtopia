# Check a download

Use downloads from the project's confirmed deployment or release. The source archive is generated by `scripts/package-release.py`; there is no signed native distribution or published checksum manifest yet.

To record a local SHA-256 checksum:

```sh
shasum -a 256 bindtopia-source.zip
```

On Linux, `sha256sum` is an alternative. A locally computed hash detects later file changes but does not prove publisher identity without a trusted comparison value.

The source archive should include AGENTS.md, the project design skill, docs and applicable license notices. It must not include Git history, hosting credentials, signing keys or personal collection backups.
