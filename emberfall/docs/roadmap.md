# Roadmap

Honest status: v0.1 is a **single-player vertical slice**, not an MMO.

| Milestone | Goal |
| --- | --- |
| 0.2 | Audio (spell, hit and ambient sounds), better camera collision, more quests and a second zone |
| 0.3 | Inventory management (drag, drop, equip choice, bags), talents, more abilities per class |
| 0.4 | Data-driven content (RON/JSON for creatures, quests, items) so designers can edit without recompiling |
| 0.5 | Client/server split: run `sim` on a headless server, thin renderer client, WebSocket protocol |
| 1.0 | Accounts, shared persistent world, party play. Requires hosting, authentication and anti-cheat design |
